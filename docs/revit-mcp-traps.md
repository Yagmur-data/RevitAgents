# Revit MCP köprüsü — bilinen tuzaklar

Revit_* ajanlarıyla çalışırken karşılaşılan, araç açıklamalarında yazmayan davranışlar.


- "unauthorized" from revit_ping = usually TWO Revit.exe running: first instance holds port 7891, the later one overwrote `%APPDATA%/Autodesk/Revit/Addins/2025/revit-mcp-token.txt`. Fix: user closes all Revit, opens one. (Explains the "MCP unauthorized" notes in Revit_Dynamo's log.)
- `revit_create_roof` failed on every profile (null `ModelCurveArray` out-arg). Fixed in source 2026-10-21 and DEPLOYED 2026-10-26 (with `edgeSlopesDeg`); roof work goes to the Revit_Roof agent. Not yet exercised live after the deploy.
- Add-in build/deploy: Revit 2025.5 here needs **net10** (`dotnet build src/RevitAddin/RevitMCPAddin.csproj -c Release -p:RevitVersion=2025`; default RevitVersion is 2026!). The post-build target copies into `%APPDATA%/Autodesk/Revit/Addins/2025`, so Revit must be closed. The net8 test project can't reference the net10 add-in (pre-existing). Pre-2026-10-26 DLLs backed up in `RevitMCPServer/.addin-backup-2025-0928`.
- Since 2026-10-26: set_parameter / set_parameter_batch / update_where / import / copy parameters pick a WRITABLE same-named parameter when the first match is read-only (RailingType "Height" = top rail), and `revit_duplicate_family_type` duplicates any ElementType (railing/stair/wall/floor/roof types), not just FamilySymbols.
- `revit_place_family_instance` with levelName=L2 (non-hosted) sets "Elevation from Level" = level elevation on some families (doubles the height). Check and reset to 0 after placing on upper levels; work-plane-based ones (desks) were fine.
- `revit_create_stair` builds risers from the walking-line LENGTH, not just level height — size run = (risers-1) × tread.
- Placed windows come in with Sill Height 0 — set it explicitly.
- Moving an exterior wall with `revit_move_element` stretches joined walls (good) but ALSO drags any floor whose sketch edge is locked to that wall face (e.g. stair landings drawn flush to the façade) — check floor bboxes/areas after moving walls and recreate them if trimmed.
- `revit_create_room` rooms get the template's Limit Offset 2438 mm; if that is below the plan's cut plane the room AND its room tags are invisible in that plan (view-scoped collectors return 0). Set Limit Offset to the storey height. Since 2026-10-26 `tag_all_in_view` with category "Rooms" places real RoomTags, and batch command `set_category_visibility` toggles a category in a view. Grids drawn in plan get vertical extents from the levels of that moment — bubbles can sit on upper windows in elevations; fix with `set_grid_vertical_extents` (added 2026-10-26). New add-in commands are callable at once via `revit_batch` (command name passes through) even before the MCP server restarts.
- `revit_place_family_instance` location = the family ORIGIN, not its centre: UK library desks (Furniture_Desk) sit at their min corner, WC_w-Cistern at the cistern back (bowl points −Y at 0°), Basin_Small at its front edge (extends +Y). After placing furniture, read bboxes (batch `get_element_geometry`) and run `revit_check_clearance` furniture↔walls before calling it done; Urinal_1 returns no bbox.

- `set_parameter` length values are taken in Revit INTERNAL units (feet) even when passed as a string: "-250" became −250 ft (−76200 mm) in a dry run. Convert (m / 0.3048) and read back the valueString.
- Since 2026-10-30 `create_stair` takes `runs` / `landingProfiles` / `treadDepth` / `runWidth` / `desiredRisers` (one Stairs with real landings). The MCP server only picks up new tool schemas after it restarts; until then call the add-in directly: POST http://127.0.0.1:7891/mcp {command, params, dryRun} with `Authorization: Bearer <revit-mcp-token.txt>`. `revit_batch` refuses self-managed-transaction commands (create_stair).
- Curtain walls cannot be slanted (Revit API refuses). For leaning glazing: Basic wall + `set_parameter` "Cross-Section" = 0 (Slanted) and "Angle From Vertical" in radians (sign: for a wall drawn with the exterior on its left, NEGATIVE leans outward); give the type one glass layer with batch/direct command `set_wall_type_layers` (added 2026-10-30). Slant changes do not show in get_element_geometry within the same batch — read back in a separate call.
