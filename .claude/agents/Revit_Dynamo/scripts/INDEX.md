# Revit_Dynamo — scripts index

|---|---|---|
| `dyn_tool.py` | stdlib-only CLI for Dynamo 3.3 `.dyn` JSON: `inspect`, `validate` (structure + CPython3 lint + Revit-2025 API-name lint), `extract` a Python node to `.py`, `embed` a `.py` into a *copy*, `extend` a copy (new Python code + NEW input nodes wired to new `IN[n]` ports + `--set 'label=value'` on existing inputs, new Uuid), `build` a new input→Python→Watch graph. Cannot run graphs. | Any time you create, edit, check or summarise a `.dyn`. Always `validate` before handoff. |
| `link_test.py` | Read-only CPython3 Python-node source: reads the open doc (title, path, Revit version, active view, counts by category, all DirectShapes with their ApplicationId/key) and writes `dynamo_link_test_result.json`. | `ForDynamo/shell-audit/ShellMeshAudit_v1.py` (node source; built into `ShellMeshAudit_v1.dyn`) | Read-only CPython3 node: finds a DirectShape by ApplicationId+key, walks Mesh/GeometryInstance geometry, welds vertices, reports (metres) open / non-manifold edges, winding flips, duplicate / degenerate / sliver triangles, edge-length stats, dihedral histogram + sharp edges, per-XY-bin defect table + worst 30 bins, stage timings -> `shell_mesh_audit_result.json` (+ `_progress.txt`). Written 2026-10-02, not yet run in Dynamo. |

## Rule
Before writing a new script: read this table (and any shared library for
this domain). Reuse or extend an existing one when it already covers the
need. Only add a new file when nothing existing does, and add its row here
in the same turn you write it.
