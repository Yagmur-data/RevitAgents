  needed, say so and hand it to `Revit_Guide` instead of building a graph.

## Graph hygiene
- Never edit a user `.dyn` in place; write `ForDynamo/<job>/<name>_vN.dyn` and
  bump N. `dyn_tool.py embed` refuses `--out` equal to the source.
- `dyn_tool.py validate` exit 0 is required before handoff, but it proves
  structure and Python syntax only — not that Dynamo/Revit will accept the run.
- `scripts/shell_audit_selftest.py` runs a mesh-audit node offline against stubbed Revit classes and a synthetic
  cube with known defects. Use it before hand-off; it proves the algorithm and JSON shape, never pythonnet/Revit
  behaviour (e.g. `mesh.get_Triangle(i).get_Index(k)` is unverified until a real Dynamo run).
- `BuiltInParameterGroup`, `ParameterType`, `UnitType`, `DisplayUnitType` don't
  exist in Revit 2025; `ElementId.IntegerValue` is obsolete — use `.Value`.

## Baklava (rhombus) panels over the GAUSS shell (built + tested offline 2026-10-02; never run in Dynamo/Revit)
- The shell is a sphere minus 3 discs (Euler -1, boundary loops: right mouth 2776 v, left arm ends 416/414 v at 1 m); the seam
  is interior and G1-smooth, so it is NOT a lattice constraint. Source: `MashProject6/` (engine copy + `baklava_panels.py`,
  V4 untouched). Engine stage key `PANEL_EDGE` (>0 = on), output `BAKLAVA_PANELS.bkl` + `baklava_report.json` next to the STL.
- Method that works: advancing-front triangulation (rows grow from every opening loop re-sampled at L) + Botsch-Kobbelt polish,
  every point projected onto the fine mesh. 6-10 s, 95 % valence-6, edges +-10 % 94 %. Plain isotropic remeshing (collapse from the
  756k mesh) took 135 s and gave only 80 % valence-6 with random grains - do not use it as the main path (it is only the fallback).
- 2D tests (overlap / crossing / node-in-triangle) on a 3D shell MUST be limited to a slab (|offset along the local normal| < 0.7 L)
  and same-facing neighbours: on a thin lens (bridge section 10 m) the opposite sheet projects onto the same footprint and made AFT
  leave holes (Euler -15) and a 1 deg sliver in a combo case. Same for clearance checks (ignore nodes with opposite normal).
- Rim panels must follow the TRUE opening polyline (store the fine boundary chain between consecutive re-sampled nodes), not the chord:
  chords cut up to ~0.9 m at tight corners. Crack tests must measure to the boundary CURVE (dense samples), not to boundary vertices
  (that gave false 'cracks').
- Limits measured: L 3..12 m work (L=12 min angle 8 deg), L>=15 degrades/fails; panel-to-shell deviation of the sub-tessellation
  grows where a rim radius is smaller than L (bridge section 10 m: 1.5 m at n=4). Size-adaptive mode (`PANEL_ADAPT`) fixes the
  deviation but costs regularity (irregular 5 -> 8-11 %) - default OFF.
- Domain walls are inherent to boundary-following rows: where opening segments differ by ~30 deg (mod 60) the lattice splits into
  grains (right arm: 3-4); each grain is a clean diamond lattice, walls carry the irregular vertices and unpaired triangles. A smooth
  field-aligned lattice (Instant-Meshes style) would remove walls but was not built. Pairing family 0 (hidden diagonal parallel
  to the rim) gives tall diamonds + a row of half-diamond triangles on every rim; family +-1 gives leaning diamonds, clean rims,
  ~35 % fewer unpaired triangles. Pairing: lock the mutual family edges first; unrestricted augmenting paths flip whole rows (stripes).
- Revit-side choices in `MashProject6_v3.py`: one DirectShape per panel (grouping slider `Panels per Revit element`), keys
  `BAKLAVA_<model key>_<5 digits>` (SetShape in place, surplus deleted), materials `BAKLAVA_Rhombus/_Triangle`, Mark/Comments. All
  of it (Material.Create, TessellatedFace(material), SetShape of 7.6k elements, transaction time) is UNVERIFIED under real Dynamo.
- Environment: no numba/compiler/rtree/networkx here (the build venv does bundle networkx) -> own projector, own matching. Bash tool:
  a heredoc holding Python with a raw triple-single-quote string broke the shell - write big files with the Write tool and splice;
  `Monitor` is disabled and `pkill` missing - poll with `timeout N bash -c 'until grep -q ...; do sleep 5; done'`.
- Tooling: `dyn_tool.py extend` copies a graph, swaps the Python code and appends new input nodes wired to new `IN[n]` ports.
- V6 package built and verified 2026-10-02 (Al approved pip + PyInstaller): `MashProject6/MashProject6_Paylas(.zip)` (5,166 zip entries, 104 MB;
  build ~3 min incl. self-test, pip served from cache). Exe STL md5 == Python engine STL == the V4 engine STL at the same settings
